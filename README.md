# CV RBB Blueprint

A locally maintained React + Vite frontend for CV. Restu Bumi Bersama.

## Development

Prefer working locally? You need Node.js and npm.

```sh
git clone <this-repository-url>
cd <repository-name>
npm install
npm run dev
```

## Built with

- TanStack Start
- TypeScript
- React
- Tailwind CSS
